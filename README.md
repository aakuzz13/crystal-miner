# crystal-miner

«Кристальная Шахта» — HTML5-кликер в стиле Cookie Clicker, без сборки и зависимостей.

## Структура

- `versions/` — все версии игры, каждая — самодостаточный HTML-файл (можно открывать напрямую, без сервера):
  - `miner-clicker-v2.html` — предыдущая версия (не изменяется).
  - `miner-clicker-v3.html` — текущая версия, редизайн под стилистику Inscryption
    (гравюрный стиль, нарисованные SVG-сцены под каждую локацию, гача-сундуки
    с шахтёрами). Все сторонние спрайты и звуки зашиты внутрь файла как base64 —
    работает сам по себе, папка `assets/` рядом не нужна.
- `assets/sprites/`, `assets/sounds/` — исходники сторонних ассетов (CC0, Kenney.nl),
  из которых собраны base64-вставки в v3. См. `docs/credits.md`. Если меняешь файл
  здесь — вручную пересобери соответствующую строку в `SPRITES`/`SOUNDS` внутри
  `miner-clicker-v3.html` (авто-синхронизации нет).
- `docs/credits.md` — источники и лицензии всех сторонних ассетов.

## Запуск

Сборки нет. Открой нужный файл из `versions/` прямо в браузере (двойной клик — оба
файла самодостаточны), либо, если удобнее, подними локальный сервер:

```
python3 -m http.server 8000
```

и открой `http://localhost:8000/versions/miner-clicker-v3.html`.

Автотестов и линтеров нет — проверяй изменения вручную в браузере.
