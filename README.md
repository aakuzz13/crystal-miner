# crystal-miner

«Кристальная Шахта» — HTML5-кликер в стиле Cookie Clicker, без сборки и зависимостей.

## Структура

- `versions/` — все версии игры:
  - `miner-clicker-v2.html` — предыдущая версия (не изменяется).
  - `miner-clicker-v3.html` — текущая версия, редизайн под стилистику Inscryption
    (гравюрный стиль, процедурные текстуры локаций, гача-сундуки с шахтёрами).
- `assets/sprites/`, `assets/sounds/` — сторонние ассеты (CC0, Kenney.nl), см. `docs/credits.md`.
- `docs/credits.md` — источники и лицензии всех сторонних ассетов.

## Запуск

Сборки нет. Открой нужный файл из `versions/` прямо в браузере, либо запусти
локальный сервер (обязательно для v3 — она подгружает звуки/спрайты по
относительным путям):

```
python3 -m http.server 8000
```

и открой `http://localhost:8000/versions/miner-clicker-v3.html`.

Автотестов и линтеров нет — проверяй изменения вручную в браузере.
